Questions Fréquentes

Combien de temps pour une réponse ?

Je lis tous les messages personnellement. Vous recevrez une réponse dans les 48 heures en général (le weekend : réponse parfois plus longue).

Vous acceptez les demandes de partenariat ?

Oui, mais à une condition : pas de perte d'indépendance. Les partenaires doivent accepter que je teste honnêtement (défauts inclus).

Je veux soumettre une machine à tester... comment ?

Via ce formulaire avec le sujet "Demander un test de produit". Je ne garantis pas que ce sera testé (file d'attente), mais vous allez recevoir une réponse claire.

Vous faites des retours pour les fabricants ?

Oui, régulièrement. Ils me contactent si un article mentionne un défaut. Je maintiens mon honnêteté mais j'écoute les corrections factuelles.

Pouvez-vous supprimer un article sur une machine ?

Non. Mais je le corrigerai si vous prouvez une erreur factuelle. La transparence c'est important, même pour les critiques.

Préférez discuter autrement ?

Le formulaire, c'est plus direct et sûr. Mais si vous avez un problème technique, vous pouvez aussi :

  • ✓ Laisser un commentaire sur l'article même
  • ✓ Signaler une erreur Google si le test semble faux
  • ✓ Nous contacter via les réseaux (si nous les activons)

Divulgation d'Affiliation

Expert Cafetière est partenaire Amazon. Quand vous achetez via nos liens (exemple : "Voir le prix sur Amazon"), nous recevons une petite commission. Vous ne payez rien de plus.

C'est transparent, régulé par la loi, et cela nous permet de tester gratuitement les machines et de recommander honnêtement — même si une machine n'est pas "la plus chère" pour nous. En savoir plus sur notre transparence.
